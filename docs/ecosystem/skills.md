# 自带技能生态 (Skills & Agents)

Atlas 随包完整分发了一套高度自洽的高阶开发、审查与压力测试套件，零外部私有依赖。

---

## 1. `atlas-grill` — 决策压力测试与代价刺破

* **定位**：重大设计决策定稿前的“红蓝对抗”工具；
* **拒绝做题疲劳**：严禁单屏抛出 4~5 个常识选择题导致用户麻木点击“全选推荐”；
* **单轮严控 1~2 问**：打透一个最要命的致命卡点，再推进下一步；
* **红蓝刺痛摊牌**：模型直接给出深思熟虑的主选方案，但**残酷亮出该方案最恶心的刺痛代价与后续反噬**，逼问人类是否认账；
* **代码矛盾核验**：方案与既有代码事实矛盾时直接指出，逼问是否推翻既有架构；
* **锐化模糊用词**：遇到“优化”、“重构”等模糊词汇，逼问正规边界。

---

## 2. `atlas-design-review` & `atlas-reviewer` — 独立复核架构

* **专用只读 Agent**：`atlas-reviewer` 工具集不含文件修改与 bash 权限，Fresh Context 进程边界隔离；
* **串行两道机制**：
  ```text
  atlas-grill（刺透隐式假设，提炼核心权衡）
         │
         ▼
    用户拍板关键抉择
         │
         ▼
  atlas-design-review（跨模型/跨厂牌独立复核，一致通过 / 不一致人工终审）
  ```
* 探索（产出问题）与验证（判定主张）严格分立，严禁审查者越界变成无休止的探索。

---

## 3. `frontend-design` — 前端品味总监与合规基线

* **两层合一架构**：
  * **第一层（品味总监）**：判读 brief、推断设计语言、调节三个设计旋钮（variance / motion / density）、禁用 AI 味套路；
  * **第二层（合规基线）**：42 份细则文件完整覆盖 WCAG 可访问性、对比度（4.5:1 / 3:1）、焦点与键盘导航、Core Web Vitals、暗色模式规范；
* 交付前由预检闸门强制校验，纯后端项目自动降级忽略。

---

## 4. §14 产物落笔纪律 (No Negative Echo 契约内化)

* **读者中立**：所有需求卡、代码注释、Git 提交与 PR 说明，必须按**“读者从未看过会话工作过程”**书写；
* **禁止反刍**：会话中被否决的备选方案、被推翻的提议、中途反复纠正的过程，属于会话控制数据，**严禁反刍进交付产物的正文与命名中**（严禁“此前曾尝试 X 失败，现改为 Y”式的纠葛叙事）；
* 产物只陈述当前敲定的正向目标、既有客观事实与架构不变式。
