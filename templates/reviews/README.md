# [域/模块名] 代码审查指引（REVIEW.md 模板）

> 供审查者在阅读具体 diff 前对齐本域审查焦点（≤10 行，不造第二真相源，语义对齐 shared/independent-review.md）。

1. **本域失败长什么样**：[例：权限是“路由进得去但按钮未禁用”、列表是“删除后缓存未同步刷新”、状态机是“并发提交造成重复实体”]
2. **重点检查**：AC 关联确定性、输入边界值、刷新后持久化复断言、错误降级兜底
3. **跳过路径**：自动生成的 mock 桩、无逻辑样式补齐、仅文案微调
4. **证据要求**：每条 finding 必须指出具体 `file:line` 并给出可操作建议；无实证猜测不予立项
5. **总结格式**：以数字开头（如“发现 2 处潜在空指针，其余通过”）；无事可修时直接声明“未发现阻断性问题”
