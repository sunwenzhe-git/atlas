# 产出面 A/B campaign 操作手册（atlas-ablate 层 3 runbook）

> 建档：2026-11-21（D206/D207）。双评审：tech-proposal-reviewer × 2 互不可见，
> 首轮「修后再审」（各 3 Blocker），修订版终审双通过。
> 上游：`skills/atlas-ablate/SKILL.md`（操作纪律）；
> `research/2026-10-23-ablation-differential.md`（方法论正文）。
> 本文承载层 3 的**多会话 campaign 操作细节**——单会话装不下的部分。

## 0. 本手册回答什么

层 1（成本账本）/层 2（守卫语料）是单会话动作，纪律在 SKILL.md。层 3 是跨会话、
跨日的实验 campaign：捆绑摘除 A/B + L0 宏观锚。本文钉死它的协议、判分、拍板与
账本表形，保证任意会话按同一口径执行。

## 1. 代际登记（campaign 的 x 轴）

- **代际 ID = 主力模型名 + 版本**，由维护者在 campaign 启动时人工声明（对齐真实
  换模型事件；不做定时巡检）。
- 每代开一个账本节：`## 代际 <ID>（声明日 <日期>）`。
- **待维护者声明首代 ID**（本 runbook 建档时未声明，首代 campaign 启动前补）。

## 2. 任务集首版（每代同一套，跨代可比是生命线）

- 来源：采纳仓（候选 = 百炼 v2 前端）**已完结任务重放 3–5 个**，规模/域分布
  首版圈定时记录进账本节头。
- **任务卫生（硬边界，缺一即样本作废）**：
  1. worktree 重置到**任务前父 commit**（`git worktree add --detach`，复用
     `scripts/atlas_eval.py` 的隔离机制；任务后文档/产物不进上下文）；
  2. **每臂独立全新会话**（B 臂不得白嫖 A 臂的探索）；
  3. 臂序随机（防学习效应单侧固化）；
  4. 跑前探针：登录态 / 路由可达（v2 实测 E2E 行因应用未拉起 SKIP——整臂跑完
     才发现靶场死 = 白烧一代预算）。
- 已知残余混淆（诚实面）：模型训练数据污染偏向**高估裸跑臂**——对 Atlas 是
  保守方向，结论反而更稳；报告措辞按 §6 降级。

## 3. 捆绑摘除 A/B 协议（短名单进层 3 后）

1. 短名单（层 1：份额>5% ∨ 0 触发；层 2 守卫豁免后）合为一组；
2. **A 臂 = 全量**（装配态原样）；**B 臂 = 全量−候选组**；
3. 摘除走 `scripts/ablation.py begin`（每臂独立事务，timebox = 任务时长上限 ×2；
   崩溃 ⇒ restore 弃该样本记缺口，install 互锁期内不重装）；
4. 同任务两臂各跑一次（同模型、同时间盒）；
5. B 臂**伤质量才二分**（log2(k)）：拆半重跑定位到机制级；
6. 每任务产出：两臂产物 + 两臂会话时长 + token 转录（§5）。

## 4. 判分协议（质量面仪器）

1. **机器主判 = 后置未参战门册**：两臂产物各自跑**含候选组的全门册**
   （L1 场景摘 X 时，X 自己参战判 B 臂——后置判是 shadow 判据，不是循环）；
   X 红 ⇒ delta>0 候选，人复核按误拦四类 + 第五类（过时拦截）分类。
2. **L0 裸跑组禁用 Atlas 门当尺**（混淆 2：裸跑臂结构性无 Atlas 产物，混测的是
   「Atlas 产不产测试」而非「模型需不需要 Atlas」）——用任务自带验收 / 产品
   自身测试保底。**代码质量与产物集合完整性分列**。
3. **人盲评最小化**：同任务两臂产物盲评（判分者不知哪臂全量），二元判断
   「B 不差于 A」+ 一句理由；rubric 固化并**版本化**随账本记。每代 6 件产物
   ≈ 30–60 分钟。
4. **质量噪声带**：首代对 1 个任务做同配置重复 2–3 次；两臂差异小于同配置
   差异基线 ⇒ 只许写 **indistinguishable**，不许写「无差异」（成本面 ±340ms
   教训在质量面的对应物）。

## 5. token 与时间转录

- 每任务操作者从宿主会话汇总**手工转录**总 token（research 侧脚本解析 usage
  JSONL 兜底），字段可空；禁 Atlas 侧遥测；放弃逐机制归因。
- 跨代账本记**原始 token + 该代币价备注**（不做货币归一，避免汇率混淆）；
  同代 A/B 内才允许比 raw token。

## 6. 措辞纪律（跨代账本效度边界）

- 报告措辞只许「**当前系统 vs 当前系统减 X**」的**方向性案例研究**
  （differential §3.1 预登记协议原文要求），禁写「净收益证明」；
- 禁写「模型变强所以 X 无用」（跨代时模型、Atlas 装配、任务环境、rubric 四者
  同变——三指纹记账把混淆显式化，不是消除）；
- 覆盖率显式分数 N/M 照旧（M = 门册实收总数）。

## 7. L0 宏观锚协议（每代 ≤6 跑，D207 豁免）

- **形态**：双独立准备快照（装配态 vs 未装配态），不经 `ablation.py` 工具、
  不进活仓切换（RFC-20261101-04「永不：整线束 on/off」已显式收窄为工具面）；
- **预登记五件套**（differential §3.1）：固定任务集 + 顺序随机 + 同一时间盒 +
  盲评 + 案例研究措辞；
- 裸跑组自带测试保底（判分协议 §4.2）；
- 双快照用后即弃，工作树零接触。

## 8. 拍板流程（四护栏逐条核）

1. 层 1/2/3 证据合流 → 按 SKILL.md §3 四护栏逐条核（保险型豁免 / 双证据 /
   持续 2 代 / 复归触发器在案否）；
2. 排序键分级（守卫冗余实证 > 过时拦截实证 > 成本份额 > A/B 案例级 delta >
   零信号；复用 30 案台账 A/B/C 三档）+ 每行「证据覆盖面」列；
3. 出**减法清单**（含观察名单）→ 维护者拍板；
4. 拍板退役 ⇒ 按 `shared/global-rules.md` §11 执行（退役即删 + 历史归 git +
   退役对称登记）；降频候选改 `shared/gates.md`「预算 + 触发物」列；
5. **复归触发器**：退役后任何 closeout 步骤 11（`shared/closeout.md`）归因命中
   「已退役门本该接住」⇒ 复活评估 + D 行登记。

## 9. 账本表形（每代一节）

```text
| 代际 | 任务id | 配置 | 后置门册红集 | 人盲评(二元+一句) | 时长 | token(可空) | 币价备注 |
|---|---|---|---|---|---|---|---|
```

节头三指纹：Atlas 装配摘要（`.atlas/VERSION` digest 算法，见 full-logo 报告 §1.2）
/ 模型标识（代际 ID）/ 任务快照摘要（父 commit + 圈定日期）+ rubric 版本号。
账本落本文件按代追加；行集合跨代增删时在节头声明对齐策略（首代未遇，遇则补）。

## 10. 首代启动清单

1. 维护者声明代际 ID（________，待补）；
2. 圈定任务集首版（3–5 个，来源仓 + 父 commit 清单）；
3. 确认实验宿主（采纳仓装配态；装配落后源包 100+ 处时先 `install.sh --update`
   重装并把「重装改变被测系统」记为混淆项）；
4. token 转录面确认（宿主会话汇总可读性）；
5. 跑层 1/2 → 出短名单 → 进层 3。
