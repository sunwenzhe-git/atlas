## 1. 方法与案例全集

**纳入标准：** 有明确修复提交或 D 行；有可抽象的症状；不是已知边界/未解观察；同根因合并。

**案例来源：** `duty-review/bugs.md`（分段计数 30 个 `#NN`，全局去重 28）、`DESIGN.md` §12（133 条 D 行，其中 D100–D135 共 36 条）、`git log` 的 fix 提交（38 条）。

**排除：** 纯功能新增/能力扩展（例如新增动词、字段通道）不计入门贡献；已知边界（图谱通道，`bugs.md:48-51`）与未解观察（`bugs.md:17/37/38`）不纳入。

**归因口径：** 三态（有门·会咬 / 有门·不够 / 无门）+ 六类漏因（A1 无门 / A2 未触发 / A3 判据不足 / A4 被绕过 / A5 预算晚 / A6 不可归因）。A2/A4/A5 需要运行账才能区分；本轮没有运行账，故不硬填。

**样本说明：** 30 案是人工按纳入标准从候选池精选的（优先有 D 行 + 有 fix 提交 + 高证据强度），不是机械随机抽样；附录 B 给的是候选池复算命令，不保证复现同一排序。

1. **判据不足是主漏因。** 30 案中 27 案事发时已有门/工具，但判据不够；只有 3 案完全无门。22 个漏放/无门案例中 19 个属「有门·不够」。这与 `gates.md` §2.5「可执行性判据本体」的「门绿而不可用」族一致（`shared/gates.md:98`）。
2. **仓内证据是修复侧的，不是运行侧的。** 22 个漏放/无门案例中，0 个有「门在修复前红过」的记录；30/30 都有事后补钉。不能据此说门从不拦截——只能说**仓内没有记录拦截**。这正是需要运行事件行的原因。**B2（事后补钉率）在本样本中因「按修复选案」而恒为 30/30，没有区分度；下一期要么用全部案例做分母，要么改用「事发前拦截率」作为主指标。**
3. **真实运行/控制台是主要发现面。** 22 个漏放/无门案例中，真跑/控制台 11、审查/上游 6、用户/巡检/现场 5。静态校验器没有直接出现在发现点；它们更多是「事后补判据」的载体。
   > **结构性警示（2026-10-23 维护者评审补注，防误引）**：此分布**条件于「已经漏出去」的案例**——纳入标准按「有修复提交 / D 行」选案，而被门当场拦住的问题不会成为案例（例：AC 反向覆盖门首跑咬出的 18 条属落地期拦截，被「纯功能新增不计入」排除在外）。回溯归因在构造上**看不见被防住的事**（预防悖论作用于方法本身），因此 11/6/5 不能读作「静态门无发现能力」，只能读作「漏出之后的发现路径分布」；门的事前拦截面归 P2 运行账与影子模式回答（§7）。
4. **误拦/噪声是真实成本。** 3/30 案例是门自身造成的假红/阻塞；全部源于判据/解析，不是产物缺陷。因为这是样本内占比、且没有全量误拦日志，**不能把它当全量误拦率**，只能当下界信号。
5. **A2/A4/A5 不可判。** 0 个案例被归为「门没跑 / 被绕过 / 预算晚」，不是因为没有，而是因为没有运行账。首跑最有价值的产出之一，是证明**下一期必须先插桩，而不是先做物理消融**。
6. **不能算净收益。** 没有逐门耗时、token、阻塞率、事发前拦截记录；任何「净收益」数字都会是编的。

**限制：**
- **样本选择偏差**：来自 D100–D135 的修复窗口，E2E 占近半；不是全仓随机样本，比例不能外推为长期比例。
- **归因是语义判断**：单人分类，20% 的 48 小时二次复核**尚未做**（本轮只做了一次性分类）；复核结果应追加，不改本报告原表。
- **发现点是文本推断**：高置信度 19 条来自 D 行明写现场/真跑/评审；中置信度 11 条由 issue/提交上下文推断；不是运行日志时间戳。
- **`bugs.md` 是工作面**：出库即删、无日期字段；案例全集主要靠 D 行 + git 重建，不能当完整历史。
- **仓外 3508/3509 未用**：逐轮真跑、人工纠偏、成本数字不在仓内；本报告不引用其结论。

## 7. 首跑裁决与下一步

**本报告支持的结论：** 先插桩，再做影子/物理消融；不要直接删门。

**建议顺序：**
1. **P2 插桩**：`atlas_check` 每行加 `duration_ms` + `.atlas/runs/check-events.jsonl`（复用 RFC 的 M4′，不造第二份）。没有它，A2/A4/A5 永远不可判。
2. **影子试点**：`validate_e2e_index`（只读、判据多、运行频繁）跑一个真实任务，记录 would-be block；不改校验器。**工具已备：`research/shadow_pilot.py`；夹具 3 轮验证通过（would-be FAIL 4/1/6、夹具逐字节未变）；真实任务待跑**。
3. **判据级消融**：选 A3 族中「语料可得」的一条判据，在隔离副本里摘除，验证补判据是否承重。
4. **门级物理消融**：等门依赖图与运行账齐了再做；本样本不支持任何删门结论。

**明确不做：** 不因「本样本 0 次事前拦截」删任何门；不把 3/30 当全量误拦率；不把 30/30 事后补钉当「门有效」；不把 E2E 占比当长期占比。
