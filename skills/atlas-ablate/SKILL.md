# atlas-ablate —— 自进化减法引擎

**目的**：Atlas 全部附加物（门 + skill + 钩子 + 流程规则）都是成本项，不是被保护
资产。模型能力持续提升后，当年必要的脚手架会变成限制（Dify/Coze 式固定工作流被
强模型淘汰是同一形态）。本 skill 是 Atlas 的新陈代谢器官：周期性出**减法清单**
——按证据强度排序的退役候选 + 证据，维护者拍板后执行退役。终极目标函数：最快、
最省 token 地达到最佳效果。

**承载三分**（单一真相源纪律）：本文件只装**操作纪律**；层 3 campaign 操作细节 =
`research/2026-11-21-ablation-outcome-campaign-runbook.md`；方法论正文（六混淆、
指标体系、保险型原理）= `research/2026-10-23-ablation-differential.md`。

## 0. 周期与触发

- **锚 = 模型代际**：代际 ID = 主力模型名+版本，由维护者人工声明（对齐真实换模型
  事件）；**不做定时巡检**（代际是事件不是时刻表，无新代际时巡检只产噪声点）。
- 真跑日（`RFC-20261114-03`）顺带采集摩擦账与后置门册数据。
- 层 1/2 单会话可完成；层 3 是多会话 campaign，一律走 runbook。

## 1. 硬边界

- 只出证据与减法清单，**退役执行一律维护者拍板**；工具永不删门/降门/改判据。
- 摘除一律走工具（`ablate_all.py` 编排器 / `ablation.py` 事务），禁止手工删改
  校验器文件。
- **宿主钉死**：实验宿主 = 采纳仓工作树 + 摘 `.atlas/` 装配副本
  （host_mode=adopter）；**源仓只跑层 1**（无信号记 N/A，不猜——2026-11-21 实测
  源仓 23 机制全 SKIP，测量面无效）。
- 绝对 ms / raw token 不跨环境、不跨代比较；同代内 A/B 才可比。
- 报告不落项目名、绝对路径、业务 case ID。
- `--fast` 跳过的行（对齐测试 / E2E 真跑）标「未纳入」，不许当 ok，不许静默省略。
- 不把 SKIP 写成 ok；不把「零破损/零信号」写成「机制无用」；不把「未测」写成
  「无价值」（减法清单每行带「证据覆盖面」列兜住）。
- 不启动服务、不杀进程、不访问生产；不执行 `--record` / `--write` / `--force` /
  `git apply` / `git checkout` / `git reset`；不把 `remediation_hint` 当修复命令。

## 2. 漏斗制三层（每代总预算 ≈ 12–30 次任务跑）

### 层 1 —— 成本账本（分钟级，先跑）

底座定位：当前目录有 `.atlas/scripts/ablate_all.py` ⇒ 用它；否则有
`scripts/ablate_all.py` ⇒ Atlas 源包根；两者都没有 ⇒ 停，不猜路径。

`ablate_all.py --root <采纳仓> --catalog-only` 盘点 → 全量摘除观测 → 在岗矩阵 +
耗时份额。**短名单 = 耗时份额 > 5% ∨ 观测窗内触发 0 次**。

### 层 2 —— 守卫收益（语料矩阵，小时级）

对短名单做守卫语料投放：各门假绿测试散在 `tests/`，能 materialize 成独立坏产物
的列进语料（T4a），投放隔离副本跑全门册记谁红（T4b，表形模板 =
`research/2026-11-04-ablation-full-logo.md`）。**有「独占接住」证据的门移出短名单**
（守卫豁免），除非有过时拦截实证。只跑层 1 的批，报告必须显式声明
「本批无收益面证据」——防退回「全绿 ⇒ 门都没用」老坑（21 次影子 0 独立信号教训）。

### 层 3 —— 产出面 A/B（campaign，走 runbook）

短名单**捆绑摘除**（全量 vs 全量−候选组）：3 任务 × 2 臂 = 6 跑；组伤质量才二分
（log2(k)，仅失败时触发）。L0 宏观锚每代一次（2 配置 × 3 任务 = 6 跑），装配级
双独立快照、不经 ablation 工具（D207）。判分 = 后置未参战门册机器主判 + 人盲评
二元最小化 + 质量噪声带——协议细节见 runbook。

## 3. 减法判据（四护栏，缺一不立案）

1. **保险型豁免清单先行**：`research/2026-10-25-net-contribution-ledger.md` 30 案
   台账 + `shared/gates.md` 灾难面（权限 / 数据丢失 / 契约破坏 / 鉴权 / CI）上的门
   **永不进减法清单**，除非守卫语料证明冗余（另一门接住同一坏输入）。
   理由：一年接一次大祸的门在 3–5 任务 A/B 里 delta 结构性 = 0，「无事件的预防
   不可见」是构造性限制，不是样本量问题（differential §3.5）。
2. **双证据立案**：产出面 delta≤0（案例级）∧（成本份额超阈 ∨ 过时拦截实证 ∨
   冗余实证）；单一证据不立案。
3. **最小持续 2 代**（跨代同任务集）；首代只进观察名单。
4. **复归触发器**：退役后 closeout 步骤 11（`shared/closeout.md` harness 复盘）
   归因命中「已退役门本该接住」⇒ 自动触发复活评估 + D 行登记。

**排序键**（证据强度）：守卫冗余实证 > 过时拦截实证 > 成本份额 > A/B 案例级
delta > 零信号（复用 30 案台账 A/B/C 三档）。**每行带「证据覆盖面」列**。

**降频档位**：低置信候选改 `shared/gates.md`「预算 + 触发物」列的触发物
（比重退役便宜且完全可逆）；**生产型机制**（gen_e2e_scripts / refresh_structure
等）退役证据走消费面（产物无人读 / 无门消费）+ 真跑日摩擦账，**不进 L1 单摘**
（摘了会改变产物集合，§3.1 混淆 1）。

**退役语义**：退役即删、历史归 git（`shared/global-rules.md` §11 无冻结档）+
退役对称登记；可逆性 = git revert + 重装。

## 4. 误拦分类（differential §4.2 四类 + 第五类）

第五类「**过时拦截**」= 拦了当前模型本可自行做对的事——「限制模型」的 measurable
形态。当前为**假设标签**（0 实例；摘掉后质量不掉才坐实）；粗筛 =
`.atlas/runs/check-events.jsonl` 处置面「明确接受 / 非缺陷」高频行，人工定性；
**不建分类器**（RFC-20261101-04 永不做 LLM 分类）。

## 5. token 与时间面

token = 每任务操作者从宿主会话汇总**手工转录**（research 侧脚本解析 usage JSONL
兜底），字段可空；**禁 Atlas 侧遥测**（宿主无关前提），放弃逐机制 token 归因
（机制提示词同会话交织，物理不可分）。速度 = 既有 duration_ms + wall time 承担。

## 6. 跨代账本（落 `research/`，本文件只链接）

每行 = 代际ID | 任务id | 配置（全量/捆绑摘除/裸跑）| 后置门册红集 | 人盲评 |
时长 | token(可空) | 币价备注 + **三指纹**（Atlas 装配摘要 / 模型标识 / 任务快照
摘要）+ rubric 版本。措辞只许「当前系统 vs 当前系统减 X」的**方向性案例研究**，
禁写「模型变强所以 X 无用」（跨代时模型与 Atlas 自身同时在变，趋势归因被演进
污染——三指纹记账就是把混淆显式化）。

## 7. 矩阵读法（2026-11-21 实测教训，v2 前端 20 机制全量实证）

- `Δ行耗时` 字段实义 = `delta_row_sum_ms` = 摘除后那一轮的**整轮合计差**，
  不是「该门省下的耗时」。
- 编排器噪声带 = 基线轮间极差，**远小于**单样本观测轮散布（实测可达 ±340ms）；
  ±120ms 内标 `attributable=true` 的小值一律按噪声读。
- 耗时结论三口径三角验证：基线单行 `duration_ms` + Δrow_sum + 摘除轮 `elapsed_ms`
  同向对齐才采信；方向异常（摘门反而变慢）先查同轮大行漂移
  （案例：serial 摘除 Δ+423ms，实为同轮 testids 行自漂 +338ms）。

## 8. 继承纪律（每条对应一次实测教训）

零命中不删门（升级为四护栏）／绝对 ms 不跨环境／同轮占比 + 配对差值 + 三口径
三角／覆盖率显式分数 N/M／SKIP≠ok／隔离副本 + sha256 逐字节还原／报告零业务
上下文／M 号引用带所属测试文件。
- 字符串替换必须 grep 断言（2026-11-21 R5：无断言 replace 静默 no-op 连吃两轮复审）。
- 判定词域先 dump 再写映射（r4 实测 pass/suspicious vs 假设值全错）；修正脚本自身也要断言。
- 派审查前先 dry-run 生成器（转义类错误只有生成才炸，review 前一次 dry-run 免费）。

## 9. 撞到就停（不要自作主张）

- 摘掉某门后整轮异常退出（硬依赖嫌疑，不是消融结果）。
- `ablation.py` 在快照形态不适用（非 git 顶层 / untracked 异常）⇒ 按
  `research/2026-11-01-ablation-real-batch-02.md` §1 手工 sha256 协议退 /tmp 整树
  副本 + 记缺口表——不为跑通改工具。
- 需要真跑 E2E 才能取到语料。
- 任何「顺手删门 / 降档」冲动（执行退役只有维护者拍板一条路）。
- 撞 RFC-20261101-04 工具面「永不」清单（自动还原 / 仓内备份 / 生产级开关 /
  自动冲突合并 / LLM 分类 / `status --json`）。
