# 调优动词（改现有页面，不是重新生成）

触发条件：brief 是对**既有界面的微调**（更醒目 / 更收敛 / 精简 / 加固 / 修字体 / 加颜色），而不是新建页面。

前置动作：先读设计档案 `product/design.md`（SKILL.md 1.E）拿当前旋钮值与设计系统。缺档案时先按 1.E 补一份再动手。

## 动词表

| 动词（用户可能的说法） | 语义 | 旋钮操作 | 典型动作 |
|---|---|---|---|
| **bolder**（更醒目 / 更有主张 / 有点平） | 现状平淡无趣 | `DESIGN_VARIANCE +2`、`MOTION_INTENSITY +2`（上限 10） | 拉开标题字级对比、换更重的 display 字重、关键 section 提高色彩对比、加一处滚动叙事或 hover 物理、放大主 CTA |
| **quieter**（更收敛 / 安静点 / 太吵） | 现状喧闹刺眼 | `DESIGN_VARIANCE -2`、`MOTION_INTENSITY -2`（下限 1） | 动效降到反馈级、色板收敛到中性 + 单强调色、加大留白、删纯装饰元素 |
| **distill**（精简 / 删繁就简） | 元素太多、主次不清 | 旋钮不动，或 `VISUAL_DENSITY -1` | 删与主任务无关的装饰、合并重复 section、一屏只留一个主 CTA、抽出页面要说的那一句话再围绕它重排 |
| **harden**（加固 / 能上生产） | 演示态 → 生产态 | 旋钮不动 | 补空态 / loading / 错误态、文字溢出（长词、多语言长度）、键盘与焦点、表单校验、边界数据（0 条 / 1 条 / N 条） |
| **typeset**（修字体排印） | 问题在字体层级 | 旋钮不动 | 按 6.K 字体裁决与 `typo-*` 细则执行：行高分档、行宽 65ch、字体按表面切 |
| **colorize**（注入颜色） | 全页灰、无记忆点 | 旋钮不动 | 引入或强化语义色板（`color-semantic-palette.md`），强调色只落在动作点，遵守 4.11 整页主题锁与单一强调色锁 |

## 规则

1. 动词增量**相对设计档案的当前值**，不是相对基线 `8 / 6 / 4`。改完把新旋钮值写回设计档案。
2. 用户用自然语言提需求时（「低调一点」），映射到最近的动词并**用一行复述**再动手：「按 quieter 执行：VARIANCE 8→6，MOTION 6→4。」
3. 一次只做一个动词，看渲染效果（截图或预览 URL）后再决定下一步。不要一次叠加多个动词。
4. 只动词条指向的部分，**不要重新生成整页**。改动过的表面仍要过预检闸门的对应块。
