# atlas 共享契约 — 门登记表（含验证预算与取证等级）

> **元规则**（`3509 §96` ⑤，2026-09-27 定形；2026-09-28 落 canonical）：
>
> 1. **注册义务**：**不在本表 = 不存在**。新增自动门必须先在本表登记一行，再上线。
> 2. **假绿测试义务**：每道自动门必须配「**喂坏输入必红**」的证明（本表最后一列）。补不齐的**登记为缺口**，不得留空装作有。
> 3. **响亮原则**：遇坏输入必须**显式失败**，或**显式可见跳过**（`SKIP` + 原因）。**静默继续 = 门失效**（`3509 §B92` 一族：守卫静默 skip / 索引静默脱节 / 台账虚挂 / 同一根因双判）。
>
> 配套：**收口清单**（`shared/closeout.md`）是人侧落地机制；本表是机器侧的**唯一总账**。

## 1. 怎么读这张表

| 列 | 含义 |
|---|---|
| 门 | 检查名（= `atlas_check` 报告里的行名，或脚本 / 测试文件路径） |
| 对账平面 | 它守的是**哪两个东西之间**的一致性 |
| 查什么 | 判据（`[机器]` = 可判定；`[语义]` = 判不了，另注承担者） |
| **不查什么** | **显式盲区** —— 写下来是为了不再指望它 |
| 最迟发现时刻（预算）+ 触发物 | 这类错**最晚**必须在这一刻被发现（`3509 §94` 验证预算公理），以及「什么时候跑」 |
| 假绿测试（取证等级） | 有没有「喂坏输入必红」的证明；**等级**见下 |

**取证等级**（`3509 §B114`，2026-09-28 新增列）：

| 等级 | 含义 |
|---|---|
| `出厂级（本轮实测）` | 本轮有实测的「喂坏输入必红」记录 |
| `出厂级（历史实测）` | 历史轮次有实测记录（指向轮次号） |
| `待复核` | 未逐条复核过它的假绿测试 —— **属缺口族**，不是「已取证」 |
| `真跑级` | 在**真实靶场**（真前端 + 真后端）跑过的证据 |
| `从未红过` | 没有任何证据表明它会咬 —— 这一格本身就是待办 |

> **上限声明**：用户 2026-09-28 裁定**暂不真跑**（`3509 §111`）⇒ 全表取证等级**上限 = 出厂级**；`真跑级` 一格未填即是当前状态的事实记录，不是遗漏。
> **本表本身不冒充已取证**：`待复核` 是**可清零**的待办 —— 2026-09-28 已逐条补齐（见各行的取证等级列）；本轮新加的门一律标 `出厂级（本轮实测）` 并附变异编号。
