# 评审记录:RFC-20261025-02(验收执行器)

> 评审方式:tech-proposal-reviewer 子代理(只读)。日期:2026-10-25。对象:v1 五步版。**总裁决:修后通过**(3 MUST + 4 SHOULD + 建设性四步替代方案);v2 已全部落实并采纳四步版。

## MUST(v2 落实)

| # | 缺陷(v1) | v2 落实 |
|---|---|---|
| M1 | run 步自起 Playwright + 再调 atlas_check 验收 ⇒ 双真跑(墙钟翻倍 + Playwright 起跑清空 `.atlas-run` 使首跑 D108 留证蒸发)或 `--fast` 绕开使门行缺席 | **run = atlas_check 默认模式为执行体**,执行器不另起 Playwright;「全批只跑一次真跑」立为本体钉(钉⑥) |
| M2 | 「批前缀态」引用不实——D110/D121 的 `ATLAS_CASE_ID` 契约 = 「当前用例 ID」,批级形态无既定语义,且 prepare 调用通道只存在于控制台 | §2.1 pre 步**新声明批级语义**:传显式串 `verify-batch` + 实现批在 prepare 契约处落诚实注记;不读该变量的存量脚本逐字节不变;逐用例分段准备仍归控制台 |
| M3 | 「产物存在跳过」未逐位落表,五步中三步产物不可判定/不可靠 | §2.2 **步骤 × 产物 × 续跑判定表**:pre 恒重跑(如实)、run 新鲜度与 Playwright 清空行为对齐(明写依赖)、report 留档 = 短路门户 |

## SHOULD(v2 落实)

| # | 缺陷(v1) | v2 落实 |
|---|---|---|
| S1 | 回填 = 第二写手候选(events.jsonl/指纹先取/claim 仲裁/console 预览纪律四题未接) | **backfill 缓行**:首批执行器写面零触碰(不写状态列、不进账本、不取 claim),竞写不存在;融合另案 |
| S2 | 独立净场步无原语,且「静置窗 = ATLAS_REFRESH_SETTLE 同族」是换用途复用旋钮 | **净场步砍除**:净场已机制化于 prepare(D110 先例);执行器不设静置参数 |
| S3 | 「六步各有产物」与五步编排口径不一;runbook 留档步无承载 | 四步口径对齐;**report 步收编留档**(`reviews/<日期>-verify/`);重装配/重生成豁免经评审判定正确(归 install.sh/gen_e2e_scripts 各理面,atlas_check 路过其门) |
| S4 | 零变化钉措辞超标(全仓逐字节永假);缺单次真跑钉与批级 ID 值形态钉;超时口径未写 | 零变化收窄为「既有套件全绿 + 行集零新增红」;钉⑥②新增;超时口径三行写实(pre 180s / run 沿 atlas_check / report 无) |

## NOTE(评审确认项)

- 前置链边界(新消费面 0/零新判据/三项不替/DDL/「E1」禁用/impact 落点另案)全部守住,无偷开。
- 既有件引用核验:除 M2 半句外全部属实(pw_runner 判据面、e2e-index 状态列唯一写手 = console submit、atlas_check 四态行形态、D110/D121/D111/D108/D148 决策行逐一对位)。
- 三个收窄判定恰当:gates 只登记不新增行、CLI 缓行(与 gen_e2e_scripts 同位阶先例)、无独立状态文件。
- **四步替代方案(评审建设性版)被 v2 全文采纳**:执行器 = 编排 + 统一报告 + 留档三件 runbook 无机器承载之事,比 v1 五步「既小又真」。
