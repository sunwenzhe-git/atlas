# 执行层能力待办（execution-layer backlog）

> **这不是 RFC。** 本文件只登记「该执行层做、但现在还没做」的能力，不授权实现。
> 任何条目落地前，仍按 `proposals/README.md` 立 RFC + 独立评审 + 测试钉。
>
> **定位（2026-10-26 维护者定）**：Trellis 只是当前选择的宿主插件，**执行层最终由 Atlas 自建**。
> 因此执行层该做的事必须在这里留底，不得因为「Trellis 现在能覆盖」就从账上消失。
>
> **边界判据**：按「应然资产 / 对账门 ⇄ 执行层」划界，不按前端/后端划界。
> Atlas 出**判据、账本、覆盖维度、门禁**；执行层出**动作、运行、证据、报告**。
> 当前 Atlas 已自行承担一小块执行层工作（Playwright 脚本生成/执行/留档，D150/D151），
> 未来自建执行层时需先做一次定界，避免两处各长一套（见 §4）。

## 5. 当前 Atlas 已承担、未来需定界的执行层工作

自建执行层时，先回答「迁出 / 保留 / 双轨」三选一，不得两处各长一套：

- **Playwright 脚本生成与执行**：`scripts/gen_e2e_scripts.py`、`e2e_console.py`、`atlas_verify.py`（D150/D151）。
- **独立审查执行器**：现由 `stack-profile` 声明、宿主子代理执行；执行层若接管，须保留 fresh context、档位不低于生成者、扇出上限 4、预算熔断。
- **项目数据准备钩子**：`atlas-prepare.mjs` 的内容归项目，调度归执行层；`ATLAS_CASE_ID` 语义不得改。

## 6. 明确不采 / 缓行（防止二次引入）

- **语义定位 + 元素漂移自愈**：与「testid 唯一硬锚」冲突。自愈会静默换定位器 ⇒ 假绿。仅允许探索期使用，证据期禁用。
- **LLM 五维评分卡（≥85 合格）**：门禁不信模型自评（`shared/independent-review.md` §4）。用严重性分级 + 指纹去重，不用分数。
- **固定配比「每个功能点 1 正向 + 3 异常/边界」**：D130 已否，会引发形式用例膨胀。
- **失败自动重试 N 次**：与「节拍类失败首跑不坐实」相反，会把真缺陷静默吸收成绿灯（`duty-review/QUEUE.md` 2026-10-18 已否）。
- **托管云沙盒**：违「项目自足」判据（`duty-review/QUEUE.md` 2026-10-18 已否）。
- **PRD → XMind**：展示层，低价值；真要做也只是十行导出器，不进主线。

## 7. 变更纪律

1. 本文件**只增不删**；完成或否决必须带日期与落点（`DESIGN.md` 决策行 / RFC 编号 / 文件路径）。
2. 条目落地前必须立 RFC + 独立评审 + 测试钉；本文件不构成实现授权。
3. 不得因为 Trellis 当前覆盖某条能力就删除条目——**Trellis 是临时插件**。
4. 新增条目须写清「Atlas 出什么判据、执行层出什么动作」，防止边界再次糊掉。
