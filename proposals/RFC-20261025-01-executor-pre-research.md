## 2. 问二:与 Trellis 的边界

三根硬锚(引既有裁决,防重开):
- **死结警告**(`DESIGN.md` §:「不改 Trellis 状态机,三状态之外新增状态会造成『状态永远不出现』的死结」)= 在 Trellis 内自建执行态**不可行**的既有裁决——自建动机的库内直接证据;
- **依赖替换级**:Trellis 现为「必需宿主执行器」(`README.md`),自建 = 依赖替换;退役对称性**必须回答**(先例:接线五触点中第 5 触点明记「单向追加、无退役对称」——那是加法,本问是替换,不同级);
- **先例引法**:引任何先例落号(如上),不靠口传。

**待验证命题**:P2-1:双轨期(自建执行层与 Trellis 并存)的最小判定面是什么——哪个门先替、哪个永远不替?验证动作 = 列 Trellis 现承担的执行语义清单 × Atlas 已有等价面,交集即候选替换序;**清单边界 = Atlas 可观察触达的语义**(apply §7 挂接面 + README + hook 面)——Trellis 仓内不可观察的语义不入表、不承诺覆盖。

## 3. 问三:非自指消费面盘点(评审修正后的正确问法)

**变异证明的定位(降位,依库内自认)**:「本变异只证明『事件行被调用』;不证明 duration_ms 的数值准确」(`research/2026-10-23-ablation-p2-mutation.md`)——变异证明 = **门的判活自检**(防「门在、判据空转」),**仍在自指域内,不得充当第二面墙**。

**真正非自指的判据,库内现有两类**:
1. **真跑级**(gates「E2E 真跑」门行 = 全仓唯一真跑级门;D108 首轮 28 构件咬合为最新活体)——**标识符注记:全文不用「E1」指此档**（E1 在库内是既有裁决号 = 原型环退役,撞号即错锚）;
2. **跨子系统消费**:生成面产出 → 独立校验面消费 → 真跑面证伪,三者代码域不同(D128 stale 即此类:HEAD/脚本变动 ⇒ stale、旧账本无指纹 ⇒ legacy,两者同等「需重审」——剔除已评审、禁勾、单列计数,重跑自动清 reviewed)。
   此外库内还有**语义级面**(独立审查族「人工复核/学习期/抽样回退」、D143 人工走查结构化块)——按 D103/D148 先例**只作如实标注、永不当判据**,填 P3-1 矩阵时单列此栏,不与两类机器/物理判据混填。

**待验证命题**:P3-1:执行层**每个生成物**能否挂上「独立子系统消费面或真跑级门面」?验证动作 = 逐生成物填「非自指消费面」列(**生成物全集 = R-3 投影 + P1-1 消费面反推的候选集,行集先声明、不得事后膨胀**);挂不上的**如实标注**(先例:D103 排除类「人工会话取出 = 纪律与盲区面,不假装是门」;D148 注红条款「注红 red 不计缺陷判据」),不允许用变异证明充数。

## 4. 本 RFC 不做什么

不写任何执行层代码;不动 apply/Trellis 五触点;不预写三问答案;不把 R-3 预判当结论;不设排期。产出 = 独立评审通过后的三张清单(消费面清单 / Trellis 语义对照表 / 生成物×非自指消费面矩阵)+ 一份立项 RFC(届时另起编号)。
