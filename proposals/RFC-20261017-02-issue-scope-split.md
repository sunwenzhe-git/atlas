## 2. 判据（v2 重写）

### 2.1 档位：只看「错在谁的意图」

| 档 | 先验判别子 | 落点 |
|---|---|---|
| **A1 判错** | atlas 的判据 / 实现 / 默认值 / 口径**与它自己声明的意图不符**（例：判据只问「文件在不在」而声明的是「能不能用」；两入口 cwd 不一致） | `duty-review/bugs.md`（须写 `file:line`） |
| **A2 装不下** | atlas 的**形态集合**表达不了真实世界的一类（例：登录三态 vs 验证码+cookie；`goto` 禁 `?` vs 宿主 tenant 只能走 URL） | 同上（**开放期就该进库**；处置后按出库规则出库） |
| — | **项目侧事实**（靶场属性 / 环境 / 构建产物 / 资产选择 / 触发面） | **永不入库**；只作条目内的「触发面 / 取证面」标注，或写进项目任务件 |

**关键**：「谁触发的」不决定档位，只决定**取证面**。#28（慢 SPA 触发）与 #30（带参页面触发）因此同档（都是 A1），v1 的「同构异判」消失。

### 2.2 拆写与接口面

- 一条问题若同时含 **atlas 侧错** 与 **项目侧事实** ⇒ 库内只写 atlas 半，并把事实标为「触发面」；项目件按需承载事实（**不是缺陷半**）。
- **接口面**：缺陷只在「atlas 与项目的交接面」成立（任一侧单独看都不错）时，归属仍是 A（atlas 承诺了那件事），但必须**双向指名**——库内行写「项目侧事实见 `<项目件>`」，项目件写「对应 atlas 侧 = `<编号 / D 行>`」。
- **历史件不回改**：`proposals/**` 与已落盘的 `REVIEW-*` 里的编号**作历史标签保留**（决策记录面，no-negative-echo）；执行者不得连坐修改。

### 2.3 出库（按 `duty-review/README.md` §4 分两类，不搞一刀切）

| 类别 | 确认条件 | 时机 |
|---|---|---|
| **机器面**（判据 / 解析 / 门） | 全量测试绿 **且** 变异即红、还原逐字节一致 | **当场出库** |
| **运行面**（真跑现场驱动） | 下一轮真跑复验通过 | 复验后出库 |

出库 = 删除条目 + **在段内「已出库锚」行**留 `编号 ⇒ D 行`（不并入族归纳），所有外部引用**改指 D 行**。

### 2.4 接口面与「判错 ∧ 装不下」共现（复审 MUST-2'）

- **接口面**（缺陷只在 atlas 与项目的交接面成立）：**若某一侧违反了自己已声明的意图 ⇒ 取 A1**（违规面可修）；**否则取 A2**（谁都没违反自己的声明，是形态集合不够用）。`file:line` 取**违约那一侧的声明行**；两侧都没违约 ⇒ 取契约正文里承诺该行为的那一节。
- **A1 ∧ A2 共现**：**主档 = 能当场修的那一面（A1）**，A2 记为「形态边界·附记（需另起决策行）」。实例 `#26`：A2（三态装不下验证码+cookie）+ A1（WARN 只喊「请声明」与「给出路」的意图不符）⇒ **主档 A1**，D103 的实际修法（改 WARN + M93）正是 A1 型；A2 附记 = 「三态之外不设第四态」。

### 2.5 引用政策（复审 MUST-4'）

| 类 | 面 | 处理 |
|---|---|---|
| **记录型**（「当时发生了什么」／决策记录） | `CHANGELOG.md`、`docs/guide/changelog.md`、`proposals/**`、`REVIEW_*`、`DESIGN.md` §12 决策行、`duty-review/QUEUE.md` 归档区 | **不回改**；编号作**历史标签**保留（`no-negative-echo`）——可解析性由库内「**已出库锚**」提供 |
| **指引型**（「现在怎么用」） | `rings/**` 契约正文、`shared/**`、代码注释（`scripts/**` / `validators/**`） | **优先只写 D 行**（D 行同处在场即不悬空）；**显式指库**的指针（如「现场实例见 `bugs.md` #26」）**必须改指 D 行** |

判据一句话：**一个 `#NN` 不悬空，当且仅当它能被解析**——要么库内锚行给了 `#NN ⇒ D 行`，要么该处已直接写 D 行。

## 6. 诚实边界

- 本 RFC 只改**登记面**；#30 的 atlas 半仍**开放**。
- 「已出库」≠「没发生」：正式记录在 `DESIGN.md` D 行 + `CHANGELOG`（README §4 原文）。
- 本 RFC 不防下次再混入（只把判据写下来）；是否给巡检器加机器判据（条目必须含 `file:line` + A1/A2 标注 + 双向指名）**不在本 RFC 范围**。
