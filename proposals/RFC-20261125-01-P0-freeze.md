## 2. 冻结 schema 与 canonical digest

- 版本化 schema：`shared/schemas/governance-common.json`、`semantic-contracts.json`、`incident.json`、`docs-governance.json`、`runtime-topology.json`、`workflow-receipt.json`。
- 唯一 canonical 序列化：UTF-8、对象键码位升序、数组按 canonical JSON 字符串升序排序、无空白、`ensure_ascii=false`；摘要 = SHA-256(serialized bytes)。生成时间不进入 canonical 业务对象。数组排序是 RFC 明示的集合摘要规则；时间线/端口顺序由各 validator 单独校验，不拿摘要替代顺序判据。
- schema 校验只支持本冻结使用的 Draft 子集：`type/const/enum/required/properties/additionalProperties/items/minItems/minProperties/minLength/uniqueItems/pattern/minimum/oneOf/allOf/if/then/else/$ref/$defs/format/propertyNames`。未知关键字与重复 JSON 键拒绝，避免“看起来支持完整 JSON Schema”。
- expected、observed、graph 三份文件、三份 schema、三个 digest；manifest 只存路径与 digest。graph digest 绑定 base/head、来源 path:line、内容 hash 与 adapter_version。
- Incident 时间线唯一权威为 `timeline.jsonl`，逐行使用 `incident-timeline-event.json`；`incident.json` 只存 `previous_status`，不内嵌事件数组。resolved→contained 回退保留 root_cause/resolution/evidence，只清 resolved_at，并追加 rollback 事件。
- Topology 节点 ID 由六字段重算；`namespace:null` 固定序列化为 `none`，空字符串非法。边端点必须存在且全 ID 唯一。JSON 解析失败 = UNVERIFIED/rc2；schema/身份/悬空边 = FAIL/rc1。
- Docs 路径拒绝绝对路径、盘符、UNC、反斜杠与 `..`；validator 还须 resolve 后做项目根 containment 与 symlink 检查。

## 6. 黄金语料与 held-out 冻结

- `tests/fixtures/governance/corpus.json` 是模块级黄金输入；`corpus-manifest.json` 固定文件 SHA-256。测试另以代码常量固定 `shared/schemas/heldout-spec.json` 的外部 SHA-256，防止与输入同批改写。
- `shared/schemas/heldout-spec.json` + `_support/governance_corpus.py` 确定性展开独立 held-out：每类语义字段/枚举/testid、Docs、Incident、Compose/Helm/Kong 各 20 正例 + 20 反例，动态 Topology 另 20 例；receipt 4 正 + 4 反；分类 initial/change/bug 各 50。展开项带 canonical fingerprint，不用 calibration 输入改写。
- 每门至少 20 正例 + 20 反例；分类每类至少 50。样本不足或误报/召回未达标 ⇒ 留 shadow，不得升 enforce。
- 变异使用现有 `scripts/mutation_proof.py` 四段协议；报告必须含注入 diff、原/后 SHA-256 和真实退出码。

## 7. P0 验收命令

```bash
pytest -q tests/test_governance_contracts.py
python3 scripts/mutation_proof.py
```

P0 只证明 schema/digest/语料边界冻结；`scripts/mutation_proof.py` 仅自检证明工具本身，不冒充治理门变异证据。各治理门必须在 `shared/gates.md` 先登记，再在对应阶段补假绿测试与 M 切片。不得据此宣称 P1–P5 已实现。
